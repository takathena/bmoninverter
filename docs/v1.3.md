# 📚 Dokumentasi Lengkap: SPF Gateway v1.3

**Deskripsi Proyek:** Sistem monitoring dan kontrol jarak jauh (IoT) untuk inverter *off-grid* Growatt SPF (5000 ES / 6000 ES Plus) menggunakan mikrokontroler ESP32 dan server lokal berbasis Python.
**Status Rilis:** v1.3 (Fokus: Keandalan Data, Keamanan Akses, dan Otomatisasi Cerdas).

---

## 1. Arsitektur Sistem (High-Level)

Sistem ini menggunakan arsitektur **Client-Polling**. ESP32 bertindak sebagai *client* yang selalu aktif mengambil data dari inverter dan mengirimkannya ke server. Server berjalan di laptop/PC lokal (tidak perlu IP publik).

```text
       [ Inverter Growatt SPF ]
                 │
                 │ (Kabel RS485: A & B)
                 ▼
          [ Modul MAX485 ]
                 │
                 │ (TX, RX, DE/RE)
                 ▼
       [ ESP32 (MicroPython) ]
       - Baca Modbus RTU
       - Watchdog & Auto-Reconnect
       - Simpan Buffer Offline
                 │
                 │ 1. HTTP POST (Kirim Data + X-API-Key)
                 │ 2. HTTP Response (Terima Perintah / Command)
                 ▼
       [ WiFi Router / LAN ]
                 │
                 ▼
+---------------------------------------------------+
|               [ Laptop / Server ]                 |
|  (Python FastAPI + SQLite)                        |
|                                                   |
|  - Validasi API Key                               |
|  - Simpan histori (SQLite)                        |
|  - Otomatisasi SOC (Cek baterai tiap detik)       |
|  - Kirim Notifikasi (Telegram API) ──> [ HP User ]|
|  - Ekspor CSV                                     |
+---------------------------------------------------+
           ▲                          ▲
           │                          │
   (HTTP POST/GET)            (HTTP GET polling)
           │                          │
           ▼                          ▼
  [ Browser (Dashboard) ] <--- (Basic Auth Login)
  - Tampilan Live & Grafik
  - Tombol Kontrol (Write Register)
  - Tombol Auto-SOC & Download CSV
```

## 2. Alur Kerja (Workflows)

### A. Alur Pembacaan Data (Read Flow)
Siklus otomatis setiap ~3 detik dari ESP32 ke Server.

```text
[ESP32 Mulai] 
      │
      ▼
[1] Baca Input Register (0-89) & Holding Register (0-44 via Modbus RTU)
      │
      ▼
[2] Susun JSON Payload
      │
      ▼
[3] HTTP POST ke Server (/api/ingest) dengan header `X-API-Key`
      │
      ▼
[Server Terima] ──> Validasi Key ──> Simpan ke SQLite ──> Update State RAM
      │
      ▼
[Dashboard] ──> Browser polling GET /api/latest (tiap 3 dtk) ──> Update UI
```

### B. Alur Kontrol Perintah (Write Flow)
Terjadi saat user mengubah settingan (misal: ganti prioritas *charge*) dari Dashboard.

```text
[User Dashboard] ──> Klik "Terapkan"
      │
      ▼
[Server] ──> Validasi Input (Range, Konflik) ──> Simpan ke Antrean (Status: "menunggu")
      │
      ▼
[ESP32] ──> POST /api/ingest (siklus berikutnya)
      │
      ▼
[Server] ──> Balas JSON: `{"commands": [{"id": 1, "reg": 2, "value": 1}]}`
      │
      ▼
[ESP32] ──> Terima Perintah
      ├─> 1. Tulis ke Modbus (Function 06)
      ├─> 2. JEDA 1000ms (Beri waktu EEPROM inverter)
      ├─> 3. Baca Ulang (Read-back) maks 3x (jeda 500ms)
      │
      ▼
[ESP32] ──> Simpan Hasil (ok/gagal) ──> POST berikutnya ──> Update Log di Server
```

### C. Alur Otomatisasi SOC (v1.3)
Server memantau data yang masuk dan mengambil keputusan otomatis berdasarkan persentase baterai (SOC).

```text
[Server] ──> Terima data baru (SOC = 25%)
      │
      ▼
[Server] ──> Cek Otomatisasi (Auto-SOC = ON)
      │
      ├─> Apakah SOC < 30%? (Ya)
      │       │
      │       ▼
      │   Buat Perintah Otomatis: Ubah Reg 2 ke 1 (PV + PLN)
      │   Kirim Notifikasi ke Telegram: "Baterai rendah!"
      │
      ├─> Apakah SOC > 85%? (Tidak)
      │
      └─> Selesai
```

## 3. Fitur Utama Berdasarkan Versi

### 🛡️ Keandalan (v1.1)
*   **Watchdog Timer (WDT):** ESP32 restart otomatis jika macet > 60 detik.
*   **Auto-Reconnect:** Menyambung ulang WiFi otomatis jika terputus.
*   **Offline Buffer:** Menyimpan hingga 10 data di RAM jika server mati, dikirim saat server hidup.
*   **Modbus Write Retry:** Jeda 1 detik & baca ulang 3x untuk memastikan perintah masuk ke EEPROM inverter.

### 🔒 Keamanan (v1.2)
*   **Basic Auth:** Dashboard dilindungi Username & Password.
*   **API Key:** Server menolak data jika ESP32 tidak menyertakan `X-API-Key`.
*   **Whitelist Register:** Hanya register tertentu yang boleh ditulis (mencegah kerusakan).

### 🧠 Otomatisasi & Fitur (v1.3)
*   **Smart SOC Automation:** Otomatis ubah mode charge ke "PV+PLN" jika baterai < 30%, dan "PV Saja" jika baterai > 85%.
*   **Notifikasi Telegram:** Kirim peringatan ke HP jika inverter *Fault* atau baterai kritis.
*   **Grafik Lanjutan:** Menampilkan Tegangan Baterai, Tegangan PLN, dan Suhu Inverter.
*   **Ekspor CSV:** Unduh histori data ke format Excel/CSV.

## 4. Detail Hardware & Wiring

*   **Mikrokontroler:** ESP32 (MicroPython)
*   **Modul RS485:** MAX485
*   **Inverter:** Growatt SPF 5000 ES / 6000 ES Plus
*   **Wiring MAX485 ke ESP32:**
    *   `VCC` -> 5V ESP32
    *   `GND` -> GND ESP32
    *   `DI` -> P17 (TX2)
    *   `RO` -> P16 (RX2) **[Wajib pakai Pembagi Tegangan: Resistor 1k & 2k]**
    *   `DE + RE` -> P4 (Disambung jadi satu)
    *   `A, B` -> Port RS485 Inverter (Tukar A/B jika gagal konek)

## 5. Peta Register Penting (Growatt SPF)

### Input Register (Read-Only / Monitoring)
| Alamat | Parameter | Skala | Satuan |
| :--- | :--- | :--- | :--- |
| 0 | Status Sistem | - | 0=Standby, 3=Fault, 5=Charge PV, dll |
| 1 & 2 | Tegangan PV 1 & 2 | 0.1 | Volt |
| 17 | Tegangan Baterai | 0.01 | Volt |
| 18 | SOC (Persentase Baterai) | 1 | % |
| 20 & 21 | Tegangan & Frekuensi PLN | 0.1 / 0.01 | V / Hz |
| 25 & 26 | Suhu Inverter & DC-DC | 0.1 | °C |
| 77-78 | Daya Baterai (+/-) | 0.1 | Watt |

### Holding Register (Read/Write / Kontrol)
| Alamat | Parameter | Nilai (Value) |
| :--- | :--- | :--- |
| 1 | Prioritas Output | 0=Baterai, 1=PV, 2=PLN |
| 2 | Prioritas Charge | 0=PV, 1=PV+PLN, 2=PV Saja |
| 3 - 6 | Jam PLN (Mulai/Selesai) | 0 - 23 |
| 22 | Buzzer | 0=Mati, 1=Nyala |
| 34 - 37 | Batas Baterai (Arus, Bulk, Float, Low) | Tergantung tipe baterai |

## 7. Cara Menjalankan

1.  **Hardware:** Rakit ESP32 + MAX485, hubungkan ke port RS485 inverter.
2.  **ESP32:** Upload `main.py` menggunakan Thonny/MPY. Pastikan Serial Monitor menunjukkan "WiFi OK" dan "Inverter menjawab di alamat 11".
3.  **Server:** Buka terminal di folder server.
    ```bash
    pip install fastapi uvicorn pydantic
    python server.py
    ```
4.  **Dashboard:** Buka browser, akses `http://<IP-Laptop>:8000`. Masukkan username `admin` dan password `growatt123`.

## 8. Troubleshooting (Pemecahan Masalah)

| Masalah | Kemungkinan Penyebab | Solusi |
| :--- | :--- | :--- |
| **Dashboard minta password terus** | Browser gagal menyimpan sesi / password salah. | Pastikan user/pass benar. Coba *Incognito Mode*. |
| **ESP32 log: `Gagal kirim ke server: 401`** | API Key tidak cocok. | Samakan string `API_KEY` di `main.py` dan `server.py`. |
| **Inverter tidak menjawab** | Kabel A/B terbalik, atau salah port RS485. | Tukar kabel A dan B. Pastikan kabel di port yang benar. |
| **Setingan gagal (Log: `gagal`)** | Inverter sibuk / EEPROM belum siap. | Klik "Terapkan" sekali lagi. Sistem sudah punya *retry* otomatis. |
| **Grafik tidak muncul** | Laptop tidak terhubung internet (Chart.js CDN). | Hubungkan laptop ke internet atau unduh Chart.js secara lokal. |
| **Notifikasi Telegram tidak masuk** | Token/Chat ID salah atau di-blokir. | Pastikan bot sudah di-*start* (`/start`) di aplikasi Telegram. |
